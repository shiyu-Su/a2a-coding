# orch 配置说明

> **本文件是 orch 单元逐键配置语义的唯一事实源**

## 配置文件

| 配置文件 | 说明 |
| - | - |
| [config.json](config.json) | 实际被读取的配置文件，配置值覆盖配置项默认值（不入库） |
| [config.json.default](config.json.default) | 用于记录配置项默认值 |
| [config.json.example](config.json.example) | 配置内容示例，首次使用可复制为同目录下 `config.json` |

## 环境变量（进程级，不进 config.json）

| 环境变量 | 说明 | 缺省 |
| - | - | - |
| `MACHINES_CONFIG` | 机器清单文件路径（`machines[]`，可选 `projectGroup` / `web` / `transport`） | `config/config.json` |
| `SESSION_DB` | 会话 / 任务库 SQLite 路径；**其所在目录即桥的 data dir**（`bridge.pid` / `logs/` / `core.lock` 均落此，便于隔离实测） | `data/sessions.sqlite` |
| `SYNC_BUDGET_MS` | `a2a_call` 的同步等待预算：到点仍未终态则返回 `working` + `taskId` 供轮询（半异步）；须小于宿主 MCP client 请求超时。`a2a_wait` 长轮询内部上限 = 本值减 5s 余量 | `30000` |

## 配置说明

### 顶级键层

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `transport` | 全字段缺省 | 对象 | 接入面。段省略 ⇒ 全缺省；非对象 ⇒ `transport 必须是对象`。详见 [`transport`键层](#transport键层) |
| `web` | 全字段缺省 | 对象 | 只读运维视图。段省略 ⇒ 全缺省；非对象 ⇒ `web 必须是对象`。详见 [`web`键层](#web键层) |
| `runner` | 全字段缺省 | 对象 | Runner 阈值。段省略 / 空段 ⇒ 全缺省；非对象 ⇒ `runner 必须是对象`。详见 [`runner`键层](#runner键层) |
| `machines` | - | 数组（**必填**） | 机器清单。缺失 / 非数组 ⇒ `machines 必须是数组`。详见 [`machines`键层](#machines键层) |
| `projectGroup` | 段缺省 = **全量接纳** | 组数组（可选） | 连接身份与可见性。段缺失 / `null` ⇒ `[]`（全部已配置机器 / 项目照常列出与派发）；非数组 ⇒ `projectGroup 必须是组数组…`。详见 [`projectGroup`键层](#projectgroup键层) |

- 未列出的顶级键**静默忽略**；退役键例外（见下）。
- 任何 JSON 解析失败、结构 / 取值非法均以 `[config]` 前缀抛错，启动时表现为拒绝 bind（exit 1）。

#### `transport`键层

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `mode` | `http` | 仅 `http` | 显式 `"stdio"` ⇒ `transport.mode "stdio" 已退役（stdio transport 不再支持）：仅接受 "http"`；其它值 ⇒ `transport.mode 必须是 "http"` |
| `http` | 全字段缺省 | 对象 | HTTP 接入面，详见 [`http`键层](#http键层) |

##### `http`键层

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `host` | `127.0.0.1` | 非空字符串 | HTTP 监听地址；非串 / 空串 ⇒ `transport.http.host 必须是非空字符串` |
| `port` | `8787` | `1`–`65535` 的整数 | 非整数 / 越界 ⇒ `transport.http.port 必须是 1-65535 的整数`。端口避开 Launcher 3100、项目 A2A 3010-3012 与回调 3200 |
| `path` | `/mcp` | 非空字符串，以 `/` 开头、**不得以 `/` 结尾**、不得为保留首段 `health` / `shutdown` / `runner` 本身或其前缀 | 尾斜杠会产生空段歧义（组身份 = URL 首段）；撞保留段 ⇒ fail-fast。非法 ⇒ 解析期报错、拒绝 bind |

- 路由：`POST /mcp`、`GET /health`、`POST /shutdown`；配组后端点亦可写成 `POST /<组名>/mcp`（组身份 = URL 首段，见 [`projectGroup`键层](#projectgroup键层)）。
- `transport` 读取失败**不回落到默认端口**（否则坏配置会静默 bind 8787 掩盖问题），直接拒绝 bind。

#### `web`键层

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `enabled` | `true` | 布尔 | 是否允许常驻桥另起只读 HTTP 工作台；非布尔 ⇒ `web.enabled 必须是布尔值` |
| `host` | `127.0.0.1` | 非空字符串 | 只校验非空字符串；**非 loopback 不在此拒绝**（loopback 拒起属运行时） |
| `port` | `3300` | `1`–`65535` 的整数 | 非整数 / 越界 ⇒ `web.port 必须是 1-65535 的整数` |
| `allowStdio` | - | 已退役 | stdio 退役后的死配置：`warn` + 忽略，不 fail-fast；解析产物不再含该字段 |

- 运行时 bind 判定 = `web.enabled && role === "owner"`（follower 不起）。
- 板侧 `bridgeUrl`（缺省 `http://127.0.0.1:3300`）读的就是本面 `/api/*`。
- 本面配置读取失败时**回落默认**（`true` / `127.0.0.1` / `3300`）并记日志，与 `transport` 的 fail-fast 策略不同。

#### `runner`键层

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `holdMs` | `25000` | 正整数（毫秒，`>=1`） | `/runner/connect` 长轮询挂起上限（空超时即心跳） |
| `heartbeatTimeoutMs` | `60000` | 正整数（毫秒，`>=1`） | 注册心跳判死阈值：超期只降在线态、不触发 stop |
| `orphanTimeoutMs` | `1800000` | 正整数（毫秒，`>=1`） | 在飞任务的**墙钟判死**阈值：`queue_state ∈ {claimed, running}` 且 `claimed_at` 早于 `now - orphanTimeoutMs` ⇒ 桥把任务置 `failed` + `queue_state='settled'` + `failure_kind='runner'`，并发 **`task.orphaned`** 事件（payload 含 `machineId` / `projectId` / `featureId` / `claimedAt` / `elapsedMs` / `timeoutMs`）⇒ Feature 静止收敛发失败账单 ⇒ 宿主 `advance(retryTaskIds)` 重派 |

- 段缺失 / 空段 ⇒ 三键全缺省；声明时三键均须为**正整数毫秒**，非法（非 number / 小数 / `0` / 负数）⇒ `<键路径> 必须是正整数（毫秒，>=1）`，解析期 fail-fast。
- **与心跳清算分工**：心跳管「机器死没死」⇒ 回 `queued`（可复活）；墙钟管「任务自己超没超」⇒ `failed` 记账交宿主。二者挂同一 `sweepIntervalMs` timer、同 tick 先 `sweepStale` 后墙钟。
- 缺省 `orphanTimeoutMs` 恒大于 machine 侧最坏总框上界；跨单元不变量的三段构成见 [../README.md](../README.md)。

#### `machines`键层

> `machines` 必须是数组；每项为一个机器对象，未列出的键静默忽略（退役键 `pushCallback` 例外：`warn` + 忽略）。

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `machineId` | - | 非空字符串 | 机器身份标识；缺失 / 非串 / 空串 ⇒ `machines[i].machineId 必须是非空字符串`。`projectGroup` 成员引用它，拼错 ⇒ 组段 fail-fast |
| `launcherUrl` | 缺省 ⇒ `""` | 非空字符串（可选） | **已作废（deprecated）**：出站指挥通道已随 Runner 反向注册退役，仅作观测 / 兼容占位。缺省或非法仅 `warn` + 归一为 `""`，**不 fail-fast、不回退全量接纳**；可继续填旧值、也可省略 |
| `token` | - | 非空字符串（可选） | per-machine Runner 鉴权 token：桥按 `machineId` 校验 Runner 注册 / 领任务 / 回传携带的静态 Bearer，**须与 machine 侧 `launcher.bridge.token` 一致**。该机未配置 token 时一律拒绝（`runner_unauthorized`，**绝不 fail-open**）；声明时非空串校验失败 ⇒ `machines[i].token 必须是非空字符串` |

- `launcherUrl` / `token` 的告警按文案做进程内 once 去重（不同机器下标各一条）；去重只作用于告警、不缓存配置。

#### `projectGroup`键层

> 形状 = **组数组** `[{ name, members: [{ machineId, projectId }] }]`；连接身份与可见性的完整语义见 [../README.md](../README.md)「连接身份与可见性」。

| 键位 | 缺省 | 合法值域 | 说明 |
| - | - | - | - |
| `name` | - | 非空字符串，字符集 `[A-Za-z0-9_-]+` | **必填**（无名组不可被寻址）。缺失 ⇒ `projectGroup[i].name 组名必填…`；字符集不符 ⇒ `…只允许字母 / 数字 / 下划线 / 连字符…`；不得与保留首段 `health` / `shutdown` / `runner` 或 `transport.http.path` 的首段冲突（撞段 ⇒ 启动 fail-fast） |
| `members` | - | **非空**数组 | 每项 `{ machineId, projectId }`，两者均须非空字符串；`machineId` 必须 ∈ `machines[]`。空数组 ⇒ `projectGroup[i].members 必须是非空数组（要么删除本段 = 全量接纳，要么列出成员）` |

- **段缺省 = 全量接纳**：不写该键 / 写 `null` ⇒ `[]`，旧配置零改动可用（`.example` 即此形态）。
- **连接身份 = URL 路径首段**：配组后宿主 MCP url 必须写成 `http://127.0.0.1:8787/<组名>/mcp`；不带组名的裸 `/mcp` ⇒ **403 `group_identity_required`**（fail-closed，**不**回退全量接纳）。
- **组间成员互斥 ⇒ 配置期 fail-fast**：同一 `(machineId, projectId)` 出现在两个组 ⇒ 桥拒绝启动、不 bind；**组内重复项**由集合去重、不算冲突。
- 成员 `machineId` 不在 `machines[]` ⇒ 桥整体拒绝该段（`machines_config_error`），且该段解析失败会让 transport 读取一并 fail-fast；`web` 各键仍回落自身缺省。
- 推荐入组机器保持 `launcher.idleStopMs > 0`（machine 侧配置，缺省 `300000`）：把项目移出组成员后靠 Launcher 空闲回收自动收回 agent；配 `0` 时该 agent 可能长期驻留，需人工停单个项目。
