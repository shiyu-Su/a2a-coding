## 关键核实结论（board `64c67953`）

1. **根因 = 映射层缺键，不是 CSS 缺失**：`nodeStateOf` 的 working 分档按两个白名单分色——`QUEUE_STATE_RUNNING = {"running"}`、`QUEUE_STATE_QUEUED = {"queued"}`（`graph-view.ts:248-250`）；引擎读面真机值域实测 = **`queueState ∈ {claimed（在飞）, settled（排队）}`**（40 条非终态 Feature 全量抽样，无 `running` 无 `queued`）⇒ 白名单永不命中 ⇒ 全落 `dg-unknown` 灰。渲染页实据：chip class 只有 `dg-done` 与 `dg-unknown` 两类。
2. **M-3 样本记录本身与真机相反（登记为事实）**：v0.10.3 改造文档 `:30` 记「板内样本 = running/queued/settled，无 claimed」且 `:22` 据此钉「不得硬编码 claimed」——今天核实**板内实际只有 claimed/settled**；当年被排除的 `claimed` 恰是在飞档。且该错值域已被单测钉成断言（`test/graph-view.test.mjs:545-547、:557`）。
3. **CSS 与图例零缺陷**：七条变体规则逐字在场、色值单一事实源（`TASK_STATE_COLORS`）、图例同入参当场出七色。
4. **同病面**：执行明细表与依赖图共用同一 `nodeStateOf` ⇒ **一处修两处好**；步条走 Feature 级派生、不同源、不受影响。
5. **次生死效（同根，修后自然复活）**：乙卡 N4 给件B 加的起轮/收口第二来源选择器 `.dg-chip.dg-running, .dg-chip.dg-queued` 在现网**永不命中** ⇒ 执行中需求的浮层件B 轮询不起轮（页级第八枚不受影响）。修映射后自动恢复。
6. **不需要引擎扩出参**：`queueState` 已在板读面白名单，纯板侧映射缺键；`claimed/settled` 值域稳定性由桥裁定，方案写「按桥实测值域补键 + 保留 unknown 不吞不猜回落」。
