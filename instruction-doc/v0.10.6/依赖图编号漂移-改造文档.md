## §2 方案设计

### 2.1 改动点 1：编号口径 F1（★用户）

`taskOrdinalMap` 比较器由 `queuedAt` 改为 **`createdAt`**：**登记时刻升序 + 同值 `taskId` 兜稳**；`null` 沉底支与 `taskId` 兜稳支**均保留**。函数签名与返回结构**不动**。

- **语义变更（须如实登记）**：编号含义由「第几个**入队**」→「第几个**登记**」。用户已裁接受。
- **两条限定（须写进 JSDoc，不得只写「登记序」）**：① **同刻登记碰撞**真实存在（实测同批登记两枚只差 45ms）⇒ 同值靠 `taskId` 兜稳，**不宣称严格登记先后序**；② **全 `null` ⇒ 整体沉底、退化为 `taskId` 字典序** —— 防御性分支，当前不触发（实测 `createdAt` 非空率 100%），**仍须写**（它是该比较器唯一的降级形态，删了后人会当多余分支清理）。

### 2.2 改动点 2：消费面（**确认结论，不改代码**）

`taskOrdinalMap` 全仓调用点**恰三处**：`graph-view.ts:405`（wrapper）、`graph-view.ts:1169`（图侧渲染，下游 `:1190`/`:1035`/`:1048`/`:414`/`:476`/`:627`）、`views.ts:738`（表侧 `:767` 首列 + `:761` 依赖列）；另有一处**按号二次排序**（`views.ts:745-750`，非第二份派生）。⇒ **改比较器一处，五面自动跟随**：图 chip 号 / `⇠#k` 角标 / 分层与列内序 / 表首列 / 依赖列。悬空依赖回落 `shortId`（`:761-762`）**不动**。

### 2.3 改动点 3：放大器 —— 配对同跳 (c)（★R1 采纳，★R2 定形）

`holdAnchor` **新增第三路**（`.pipe` 豁免**保留**，只额外继承整页展开态）：

```js
function holdAnchor(el) {
  var ae = document.activeElement;
  if (ae !== null && isInputFace(ae) && el.contains(ae)) return true;                                   // 判据① 逐字不动
  if (el.querySelector("details[open]:not(.pipe)") !== null) return true;                               // 判据② 逐字不动
  return el.hasAttribute("data-live-lock") && document.querySelector("details[open]:not(.pipe)") !== null;  // 新增第三路
}
```

- **标记**：`views.ts` graph 锚（`<div class="live-slot" data-live="graph">`）加 **`data-live-lock` 恰 1 处**；`exec` / `steps` / `turn` / `turn-prog` / `sched-board` / 任务页各锚**一律不加**（逐枚点名）。
- **不动项**：判据①（填表焦点）③（拖拽）④（后台页）、`isInputFace` 双份同体、`addEventListener` 恰 6、排拍字面恰 1、不新增监听 / 脚本 / 第九枚。
- **★R2 新事实 —— 跨浮层泄漏（(C) 裁定 = 接受 `c-doc` 并登记）**：浮层 `#feat-dialog` 渲染在 `</main>` 之外、由件B 把回包 `<main>` 搬入 `.fd-body` ⇒ 浮层里那份 graph 锚**也带** `data-live-lock`，而 `document.querySelector` 是整篇作用域 ⇒ **浮层内展开折叠会冻住背后页的 graph 锚，反向同理**。**判定 = 可接受**：① 浮层是 modal、背后不可见，关浮层即恢复；② 浮层内两块本就由件B **原子换整份 `<main>`** ⇒ 天然同快照，本卡 lock 在浮层内不构成第二道保证、也不制造新错位。**代价 = 注释与测试钉里如实登记该跨面语义**（否则后人会当缺陷修掉）。备选 `c-scope`（`el.closest("main")` 收窄）不采用：更复杂且对浮层内零增益。

### 2.4 改动点 4：语义与连带登记

- 编号与时长**不再同键**：表**行序 = 登记序**，而「排队时长」列 = `formatDurationBetween(t.queuedAt, t.claimedAt)`（`views.ts:781`）、trace 位次 `position` 由桥给（`queuedAt` 同键）⇒ 二者不同序。
- **书面落点（★R2 更址）**：`src/derive.ts:714` 的 **`TRACE_READ_NOTE` 常量本体**加半句（行序 = 登记序；时长列与 trace 位次仍以入队时刻为键、二者不同序）；**不改** `views.ts:815` 模板处（避免新增第二枚 `<p class="hint">` 结构）。该常量既有三枚 `assert.match`（非逐字等）⇒ 加句子零翻案。
- **README 不新增章节**（宿主裁定）：全仓 grep 该口径**零命中可写面**，「README 无该口径可写面」这一事实本身登记 §6。

### 2.5 明确不做

不改依赖图连线 / 几何 / 传递约简；不改引擎 / 协议 / 数据面；不动卡片其余区块；不引入内联脚本（八元闭集不扩）；**不顺手修 ⟳ 钮在 held 锚上失效**（既有缺陷 ⇒ §6 登记、另卡）。
