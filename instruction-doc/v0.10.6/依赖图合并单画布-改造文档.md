## §1 背景与评估

- **目标**：把板「需求详情页 · 依赖图」从「按 project 分管道、**每管道一枚独立 SVG 画布**」**合并为一张画布**；各 project 以**带标题的几何框**呈现；**跨管道依赖边画成真连线**（替代 `⇠#k` 角标），并与同管道边同受既有三条硬判据（端点落节点边框线中点 / 连线不重叠 / 连线不穿节点）。
- **评估结论：合理**（纯 board 渲染层改造，不改数据面 / 引擎 / 协议）。
- **用户已裁（2026-10-14「按建议」）**：**② 走线形态 = (A) 框外公共通道带**；**③ 框内保留逐管道密列**；**④ `⇠#k` 角标全退役**；**⑤ 出原型对照稿**；**⑦ 框保留逐框折叠 = `<details class="pipe" open>`**。
- **一处需登记的因果（易误读点，非缺陷）**：同版 `8af7f099`（flow「DAG 依赖只声明直接前置」）+ 既有 `transitiveReduce` 已删冗余边 ⇒ **合并后画布上的跨框真连线数量会明显少于「声明边数」**（本例 `eb86d5e8` 声明 31 边、本质 28 边、跨框仅 3 条）。验收**不得据此判「图变空了」**；h2 的「声明 / 本质 / 省略」三数正是这一因果的对账面。

## §2 方案设计

### 2.1 架构判断：统一坐标系 + 单画布（board R1）· 与 ⑦(ii) 逼出的形态 S1（board R2）

**R1**：合并后跨框连线与框内连线**占据同一视觉空间**，而 `routeIntraEdges` 的三套装箱（`busLane` 按 x 区间、`λ` 按 `a.col`、`μ` 按 `b.col-1`）都逐 grid 独立跑 ⇒ 不同 grid 的 lane 号在画布上是同一根线。⇒ **「不叠线」判据 I3 只有在统一坐标系 + 统一一趟装箱里才可机械核验**。两条衍生约束：① 几何用**平移算子**把每枚 grid 抬进画布空间（**不是**靠 CSS 偏移各框 —— 那会让跨框边与框内边分处两个 svg、互不可检）；② 画布内**恰一枚** `<svg class="dg-links">`。

**R2 · S1（⑦(ii) 强制）**：框若是可折叠 `<details class="pipe" open>`，则**该框的 chip 必须在其子树内**（否则折叠后 chip 仍可见 = 语义假动作）。遂定 S1：

| | R1 隐含形态（S2，框为纯几何 div） | **⑦(ii) 强制形态 S1（采用）** |
|---|---|---|
| `.dg-cell` 坐标 | 画布绝对坐标、cell 提升为 canvas 直接子节点 | **逐字沿用今日局部坐标**，cell 仍在「框 › `.pipe-body` › `.dg-grid`」内 |
| `svg.dg-links` | 画布恰一枚 | **画布恰一枚**（从框内**搬出**到 canvas 层） |
| 折叠一框 | 无效 | **有效**（chip 随框消失，框矩形仍占位） |

⇒ **C1 平移算子消费面收窄**：`shiftPipeGrid` **只喂走线**（path 坐标进画布空间、供统一装箱与 I1/I3 核验），**不喂渲染**（DOM 里不出现画布坐标）。

> **`a0682281` 订正**：喂给 `shiftPipeGrid` 的平移量必须是**框内缘原点** = `frame.dx + DG_GRID_ORIGIN_X` / `frame.dy + DG_GRID_ORIGIN_Y`，**不是框外缘** `frame.dx/dy`（后者只描述框矩形位置、用于 `renderFrame` 的 inline 与带层）。详见 §6 增补节件一。

⇒ **新的硬约束（R1 没有，R2 补）**：**框必须绝对定位 + 固定 `width/height`**。理由机械可核 —— 若框走块流（今日 `.pipe{margin-bottom:…}`），用户折叠任一框 ⇒ `<details>` 塌缩 ⇒ 其下所有框整体上移 ⇒ 而画布级 SVG 的 path 坐标是 SSR 时按「全展开」算的 ⇒ **跨框线与框内线全部错位**。固定盒 + 绝对定位 ⇒ 塌缩只让该框体变空、**不移动坐标系原点**。

⇒ **一条 CSS 警告（⑦(ii) 专属、离线单测抓不到）**：框层（`.pipe` / `.pipe-body` / `.dg-grid`）**不得设 `z-index` / `transform` / `opacity`** —— `.dg-cell{z-index:2}` 与 `svg.dg-links{z-index:1}` 的比序依赖二者处于**同一堆叠上下文**；任一框层设了上述属性即自成上下文 ⇒ 画布线被关在框下 ⇒ **线压在 chip 上**。

四点口径：
1. **`summary` 字面逐字不动**（`管道 {projectId}（N）` + glyphs 串）⇒「三轮N1-③ project 在管道头」「三轮N1-④ 转义」两族锚**不翻**。
2. **`--dg-nw/--dg-nh/--dg-bh` 上抬到画布一枚 inline 下发一次**（自定义属性天然继承）⇒ G6-同源①② 不翻。
3. **inline `style` 几何字面分三档**：`.dg-cell` 仍**恰 `left/top` 两枚**（锚不翻）；`.dg-canvas` = `width/height` + 变量；**框 = `left/top/width/height` 四枚**。三档**一律零 `position:` 声明**（定位只从 CSS 类给）。
4. **带引号属性闭集仍 = `class`/`title`/`style`/`d` 四枚**（G8-svg负钉②）—— **不新增第五枚**，尤其**不得为「折叠后隐藏相关线」给 path 加 `data-*`**（见 §2.5-代价 5.2）。

### 2.3 跨管道走线 = **(A) 框外公共通道带**（用户 2026-10-14 裁定）

**形状**：三段式（源侧通道**竖直** → 框间带**水平**横移 → 目标侧通道**竖直**再水平入），即既有 `busPath`（弧→水平→弧）**绕 90° 的同一家族**；拐角各一枚 C 弧、**切线连续**（不得出硬直角）。
**落点**：新原语 `crossPath()` + `routeCrossFrameEdges()`；**框间空隙高度 = 装箱后按需撑开**：`gapH[i] = max(DG_FRAME_GAP_MIN, 2*DG_CROSS_MIN + lanes*DG_BUS_PITCH)`，与既有 `gapW[c] = max(DG_COL_GAP_MIN, DG_LANE_MIN*2 + n*DG_LANE_PITCH)` **完全同构**（同一 `packLanes` 换轴用）⇒ **不引入第二套几何概念**。
**回流档**：目标框在源框**上方**时走**画布外围 gutter**（左/右边缘各留一枚 lane），仍是通道带家族、只多一个档位。**本卡样本 3 条跨框边全为回流**（`eb36…`：`O3→B6`、`O7→C1`、`F12→C1`，目标均在 board 框）。
**判据**：**不破 I1**（横移段 y 落框间空隙、竖直腿 x 落列间通道 / 框 pad，结构上无 chip），且**由构造成立**。
**障碍集（判据加强、非放松）**：`G4-穿节点` 障碍集从「chip」扩为 **chip ∪ 框标题带 ∪ 框边框 ∪ 兄弟框整块矩形**。最后一项是 ⑦(ii) 新面：跨框线竖直腿**不得从任何其它框的矩形里穿过**（只能走框间空隙带 / 画布 gutter）。

> **`435b8695`（第二枚增补）A6 订正 · 障碍集带域化**：`O1` = **全体 chip（除本边两端）**；`O2` = **非本边两端所属框**的整块矩形（含其标题带与边框）。—— 原句未限定**归属**，而 `2k+3` 段形的**出口 / 入口腿必然穿过自己框的边框与标题带**（入口腿就是从框间带进框），照字面会把**正确形态判红**。**本订正只写本改造文档、不动 flow。**

**(B) 框间直连为何不采（board 机械论据）**：直连曲线包围盒 = 两端 x/y 区间 ⇒ 跨框时**必然覆盖源框右侧全部列与目标框左侧全部列**，那些列里有 chip ⇒ **G4-穿节点②③ 直接判红**。要救只有「显式豁免 I1」或「加避让（= 重新发明 A）」。**记为「已评估、因破 I1 不采纳」。**

3. **不改免手刷跳拍判据字面**：`PAGE_LIVE_SCRIPT` 内 `details[open]:not(.pipe)` 两处**逐字不动**。
4. **不动既有走线公式**：`arcPath` / `busPath` / `arcK` / `packLanes` / `busLaneY` 函数体不改，只被跨框档复用 / 并列。
5. **零新增内联脚本**（八元闭集不扩）、**零新端点**、**零新数据源**、**不碰浮层 `dialog.fd` 侧**。
6. **不改协议、不引入新 `taskType` / `roles` / `stage` / `state` 值域**、**不引入新机器门**。
7. **不做交互式避让**（拖拽 / 缩放 / pan）。

**两处「看似该动、本版刻意不动」**：
- **`DG_COL_GAP_MIN` 数值不动**（现 56，其 56 与角标越界「取等」）：它进 `colX` 递推式 ⇒ 改它 = 全体 chip 横坐标漂移 = G2/G3/G4/G5 整族坐标锚翻案。本版**只动 `DG_PAD_R`**（只进 `width` 一条式子）；`DG_COL_GAP_MIN` 加注释重定为「通道带宽下界 = 2·DG_LANE_MIN + 余量」、**数值不动**。
