## 1. 要解决什么问题

**问题一句话**：管理页上**两张表的信息高度重叠**（`#1 成员（声明态）` 只有 `machineId | projectId` 两列，正是 `#10 项目（运行态）` 的**前两列**），用户觉得重复；且用户原本以为版本信息该落在「成员表」上，实际它落在了最底部的「项目表」⇒ 期望 = **项目表置顶、成员（声明态）表去掉**。

**当前行为（宿主直连板实测 + board 核实）**：`GET /org/<名>/manage` 共 **8 张同级兄弟卡 + `<h2>`**：

| 卡 | 渲染函数 | 内容 |
|---|---|---|
| **#1 成员（声明态 · `GET /api/groups` 该组投影）** | `renderOrgMemberSection` `views.ts:1580-1622`（调用点 `:1808`） | 表 `machineId \| projectId`，**纯只读、零按钮**；卡头带「观测时刻 X」 |
| #2 加/删项目（两栏拖拽） | `renderMemberPoolColumns` `views.ts:1475-1526` | 项目池 ↔ 本组（**成员写面**） |
| #3–#5 成员（项目组台账）+ 加/删成员表单 | `renderMemberForms` `:1390-1422` · `renderMemberFormsFold` `:1430-1435` | 增删成员提交入口 |
| #6/#7 agent 配置 / 停用本组织 | — | — |
| #8 配置核对 | `:1651-1730` 一带 | 三源（含本版新增第三行） |
| #9 需求简表 | — | 本组 186 条 |
| **#10 项目（运行态）** | `renderOrgProjectsTable` `views.ts:1255-1310`（调用点 `:1815`） | `machineId \| projectId \| **已发布的最新版本号** \| agentKind \| a2aPort \| status \| startedAt \| 机器 error` |

**期望行为**：`#10 项目表` 移到**最上**；`#1 成员（声明态）表` **整卡去掉**。

## 2. 核实结论（board `19d5efa8`，逐条 file:line）

### 2-1 落点与最小改法
- **只改 `renderOrgSpaceManagePage` 的模板串（`views.ts:1807-1815`）两行**：把 `:1815` 的 `${renderOrgProjectsTable(...)}` 上移到 `<h2>` 之后；删掉 `:1808` 的 `${renderOrgMemberSection(...)}`。
- **不动 `server.ts`**：`groupsOutcome` 入参必须**继续传**（池右栏 + 配置核对卡 + 板侧差集都吃它）⇒ **装配面零改动**。**不存在第二处「顺序事实源」**。
- 两函数均**模块私有**，全仓各仅两处引用（定义 + 调用），**无第三处** ⇒ 删除安全。

### 2-2 「去掉 #1 不丢能力」—— 成立（三处实证零耦合）
- `#2` 两栏拖拽直接取 `groupsOutcome…members`（`:1496-1497`），不吃 #1 的 DOM；`#member-pool` 封在本卡体内（`:1514-1523`）。
- `#4/#5` 表单是纯 SSR 静态表单，零 #1 引用。
- `MEMBER_DRAG_SCRIPT`（`layout.ts:788-880`）靠 `getElementById("member-pool")` + `data-side` 冒泡 ⇒ **与 #1 零耦合**。
- 声明面 `groupsOutcome` 另有 **5 处**消费者（池右栏 / 核对卡首行+warnings+checkedAt / 板侧差集 `orgs-view.ts:433-438` / 空间任务页归属过滤 `server.ts:1264` / 回执页复用 `server.ts:3094`）⇒ **删卡不使其成为死数据**；**用户已知的「配置核对卡第 1 行」确为独立消费者**（该行核对的是**那次读取的健康度**，不是那张卡）。
- **「本组成员完整清单」不减**（池右栏逐行 `machineId/projectId` + 末位标记）⇒ **用户的「重复」判断成立**。

### 2-3 ⚠ 但有两处**诚实通道损失**（超出「重复」范畴，须用户裁）
1. **「未声明」档无承接位**：`views.ts:1597-1603` 的「声明面无该组 ⇒ **未声明** + 指向『首次写入即建组带首成员』」在别处**没有等价表述** —— 池右栏把「**组未声明**」与「**已声明但成员为空**」**塌成同一句**（`:1508`）。而**写侧对口径是敏感的**（对照 `test/group-admin.test.mjs:268`：「声明面无该组 = 幂等零写入，**不得**翻译成末位不可删」）。
2. **声明面 `observedAt` 的可见承载收窄**：现 `#1` 卡头**恒**带「观测时刻 X」（`:1612-1615`）；删后只剩「配置齐备 · 上次核对时间 X」（`:1711`），**而该行仅在全部源可读 ∧ 无 warn 时才渲** ⇒ **降级档下 3300 的观测时刻不再上页**。

### 2-4 锚影响面（本增补体量主要来源）
- **A 因删 #1 而红：8 个位置 / 9 条断言** —— `test/orgs-page.test.mjs`（`:254` N3-① · `:303` N6-⑧ · `:588-611` BD5-③ 共 4 条 · `:613-628` BD5-③b「未声明」2 条 · `:630-647` BD5-④ 1 条 · `:649-666` BD5-⑤ 1 条）· `piece5-space-cards.test.mjs:101`（+ 头注 `line 7`）· `org-pool-two-column.test.mjs:378`（池-⑬）。
- **B 已逐一排除、确认不红**：`n3-regression-anchors` **无「b-card 计数 / 区块顺序」结构锁**（宿主候选假设**被证伪**，该文件对 manage 页只有 `:471` 脚本字面 + `:721` 根因码落点两处锚）· `v0102-manage-read-and-origin-anchors` **零改** · `v0102-manage-project-column` 安全 · `org-deeplink-home-org-c3:157-190` 位置无关 · `org-pool-drag` 全活 · 其余若干页面测试全活。
- **★ 根回归套件零命中**（`.omo/skills/regression-test/` 全库 grep 无匹配）⇒ **板外无锚、无需根侧同步**。
- **C 置顶侧唯一脆弱点（非阻塞）**：`org-pool-two-column.test.mjs:246` 的切片**右界取全局首个字面 `class="hint"`**；已核项目卡三档**不产**该字面 ⇒ **现在不红**，但属「沉默正确」（日后项目卡新增裸 `hint` 会静默截空）。
- **净账**：`#1` 侧 9 条改判/消失；**置顶侧 0 条红**；⚠「**条数不减**」**需补 ≥3 条新锚**才持平。

### 2-5 置顶 vs 拖拽守卫：**不撞**
8 张卡为**同级兄弟、零嵌套**；`#member-pool` 封在池卡体内 ⇒ 置顶 = **兄弟序位移、DOM 层级不变** ⇒ 既有纪律「**容器恒在交互容器之外**」**自动满足**；`MEMBER_DRAG_SCRIPT` 靠 id/`data-side` **不依赖位置**；`DRAG_SCHEDULE_SCRIPT` 只挂排期页、本页不注入；全站 CSS 无页级位置选择器。

### 2-6 措辞面
- 配置核对卡**第 1 行字面**「声明面成员（3300 `GET /api/groups`）」**仍准确、不得删**（它核对那次读取的健康度）。
- 需去位置化两处：核对卡卡头副标（`:1722-1726`）与函数 doc「核对的是**上面各区**那次读取的健康度」（`:1629-1630`）。
- **文档同步**：`README.md:118` 的 manage 页结构长描述（区块 ①②…⑤ + 「成员两栏拖拽 = 成员区上方」）**必须重写**；`:164`「现势读面恰三处」**不含 #1 ⇒ 不动**。

### 2-7 体量与拆节点
- **无硬约束级风险**。
- 源码：模板串 **2 行位移** + `renderOrgMemberSection` **整函数退役（约 50 行含 doc）** + **3 处悬挂文字**（`views.ts:1524` hint「两栏与上方「成员（声明态）」同源」· `:1467-1468` / `:1791-1805` doc · `server.ts:2097-2100` doc）+ 核对卡措辞 1 处。
- 测试：9 条改判 + **≥3 条新增**（+ 可选 4 处切片加固）。
- **拆 2 个节点即可**（① `views.ts` 重排 + 删函数 + 措辞；② 测试锚改判 + 新增），均在 10 分钟粒度内；README 可并入 ①。

**产品经理结论（本 project 接不接）：接**（读投影面改动，不触数据面 / 引擎 / 协议 / 写面，与 `f2dcb141` 同 Group Version，符合增补档）。
