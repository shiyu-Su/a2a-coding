## 1. 问题一句话

排期页横着一块**组织级**的「各 project 版本总览」（答的是"本组这一版各 project 落哪号"，**与具体需求无关**）⇒ 用户视角"莫名其妙"；而**需求维度**的「**这条**需求在各 project 落哪个版本」板上**完全没有**（板根本没解析引擎已有的归属读面）。⇒ 本次**把信息按维度分流**：组织面 → 管理页；需求面 → 需求卡片；排期页清空。
